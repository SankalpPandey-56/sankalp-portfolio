## 💡 Overview

Built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and custom WebGL/Canvas fluid physics.

---

## ⚡ Signature Feature: Venom-Inspired Liquid Symbiote Transition

A custom theme transition between dark and light modes inspired by Venom's symbiote suit-up visual:
- **Procedural Tendril Growth:** 28 directional tendrils snake outward with fractal sub-branching and dynamic curvature.
- **Fluid Surface Tension:** Rendered via an HTML5 canvas and processed through an SVG filter pipeline (`<feGaussianBlur>`, high-contrast `<feColorMatrix>` thresholding, and fractal `<feDisplacementMap>` turbulence).
- **Zero-Flicker DOM Swapping:** The underlying theme state flips only while 100% of the viewport is completely occluded.
- **Cellular Dissolution:** Retracts via an organic biological iris mask to reveal the inverted interface.
- **Accessibility:** Full `prefers-reduced-motion` compliance.

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/SankalpPandey-56/sankalp-portfolio-2026.git
cd sankalp-portfolio-2026

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
npm run build
npm run start
```
